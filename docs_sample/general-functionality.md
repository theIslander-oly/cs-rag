## General Functionality

### Exporting a table

Any table view (ticket list, agent list, report results) has an **Export**
button in its top-right corner.
![the Export button](img/export-button.png)
Choose CSV or XLSX. The export includes exactly the columns currently shown
in the table and respects any active filters — it does not export the full
unfiltered dataset.

### Keyboard shortcuts

Press `?` anywhere in the app to open the shortcuts overlay. The most used
shortcuts are `g` then `t` (go to ticket list), `c` (create ticket), and `/`
(focus the search bar).

### Notifications

In-app notifications appear via the bell icon in the top navigation bar.
Email and Slack notifications are configured separately under **Personal
Settings > Notifications**, and can be set independently per event type
(assigned to me, mentioned in a comment, ticket escalated, SLA breach
warning).
