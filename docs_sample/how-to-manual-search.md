## Searching for Tickets

### Quick search

The search bar at the top of every page searches ticket subject, description,
and comments. Results appear as you type after the third character.

### Advanced search

Click **Advanced Search** next to the search bar to filter by status,
priority, category, assignee, team, and date range in combination.
![the Advanced Search panel](img/advanced-search-panel.png)
See [Search Fields](search-fields.md) for the full list of filterable fields
and which ones support multi-select.

### Default sort order

> **Note:** Two earlier drafts of this section disagreed on the default sort
> order — one said results are sorted by relevance, the other by newest
> first. Neither draft cited a source. Until this is confirmed against the
> live product, treat the sort order as unverified rather than assuming
> either answer.

### Saving a search

Any combination of filters can be saved as a **Saved View** using the star
icon next to the results count. Saved Views appear in the left sidebar and
are private to the agent who created them unless explicitly shared with a
team.
